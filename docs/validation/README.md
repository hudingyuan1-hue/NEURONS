## 修复轨迹

- 初次布局151检查6失败，归为床头柜接近点落入椅子碰撞、半格浮点取整两类。移站位及确定性量化后158/0；再补起终点和整段完整半径，重测仍158/0。
- 初次规则浮点残余阻止0.5秒动作结束，定向修复；审查补0.25秒受伤硬直、独立1秒失神、受击取消搜索/待发技能、不重复刷新，共71/0。
- 初轮截图见菜单/底栏文字互穿、默认房间底边被底栏遮挡、配对手端间隙，修正UI实色信息带、内部基准取景、共同手锚后复跑。
- 最后发现关屏完毕瞬间可绕过手动暂停结算身体反应，改为统一暂停门控后再apply_pending，新增集成断言；最终19/0，stderr无错误。
