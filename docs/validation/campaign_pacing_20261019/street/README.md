玩家目标是阻止宿主逃离。此样本表示约82秒自主逃离压力；NPC打伤与耽搁属于玩家被动获益，不能当作玩家难度更高。资源入场20神经元/7神经簇、离场24/7；本夹具仅初始皮肤刺激已解锁，每主段都有约13–21秒可提交机会，费用1神经元、原冷却2秒。真实全流程无消费样本终态为56神经元/13神经簇，不能据此夹具认定正常玩家无法解锁掌控。窗口按实际样本时间加权，四分之一秒抽样误差保留；菜单冻结还允许玩家停下来决策。

已见具体问题：压力并非逐段递增。出口四名敌人有原配置，但本轮均未起手；宿主沿中线以1.15m/s离开，上下分散人物以0.85m/s接近。街道段有跨段追兵，节点才发生有效命中。窄道沿实际样本的静态横截面最小约4.48m，节点约3.18m；不含动态人物/床，不能直接当有效战斗通路。无超过0.84秒的未解释静止，无门口软锁。

最小后续：先用现有合法干预做同档对照，检查付费操作能否实际改变宿主路线/遭遇/逃离结果；再判断是否只需可见性/反馈提示。暂不延长路程、添敌、改伤害或强制支路。需要进一步证明的仍是玩家干预的可解释收益及逐关学习曲线，本批未以无人操作基线冒充完整玩法验收。

`summary.json`汇总七段、来源哈希、资源、窗口与局限；各子目录保留初始/Street入口/最终完整快照、所有事实和人物阶段、0.25秒时序、逐房实机截图及空stderr。上述自然主路没有连续录屏，后续对照录像见下节；无人工/耳验结论。r1抽样权重及对白冻结误计已在分析与支路r2纠正，旧证据保留；未由此改游戏规则。本批进程均自行退出。
